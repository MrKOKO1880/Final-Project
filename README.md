# Final Project

A framework-free five-page portfolio site ready for GitHub Pages.

Target repository: `https://github.com/MrKOKO1880/Final-Project`

## Pages

- `index.html` - Home
- `project.html` - Project
- `assignment.html` - Assignment
- `presentation.html` - Individual Presentation slide surface
- `about.html` - About Me

## Local preview

Open `index.html` directly, or run this from the current folder:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish to Final-Project

1. Open `https://github.com/MrKOKO1880/Final-Project`.
2. Upload the contents of this folder to the repository root. Keep all HTML, CSS,
   JavaScript, and README files at the same level as `index.html`.
3. Open `Settings > Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`, then save.
6. Visit `https://mrkoko1880.github.io/Final-Project/` after one or two minutes.

## Replace before publishing

- `Your Name` and all personal copy
- Four project names, descriptions, categories, years, and links
- Four assignment names, descriptions, weeks, and links
- Location, focus, and availability
- `hello@yourname.com`
- GitHub and LinkedIn links

The navigation is generated from `site.js`. All page copy lives in the individual
HTML files, and the unified visual system lives in `styles.css`.
